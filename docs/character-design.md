# 《一二布布：萌境奇旅》角色设计

## 视觉与叙事总纲

萌境由八片会移动的梦境岛屿组成。每位旅伴都有一枚“心愿碎片”，碎片在互相帮助时发光，争执与误会会让光芒变暗。角色卡同时承担三个功能：玩家的长期能力、桌面上的情绪表达、以及触发剧情的入口。所有角色均为原创动物或幻想生物，不对应现实品牌形象。

角色数值说明：活力是角色承受风险的能力，降至 0 会进入“疲惫”而暂时失去行动；友情值 0–6 代表与全队的平均信任；专属技能每回合最多使用一次，除非卡牌明确刷新。

## 12 名角色

### 1. 一二｜星轨小鹿
- **种族 / 年龄感**：星轨鹿，少年感。
- **外观**：月白鹿毛，额心有两颗并列星斑，耳尖像蓝色书签；披短斗篷，内衬画着会转动的星图。
- **性格**：安静、敏锐、先观察后行动。嘴硬但会把最好的位置让给朋友。
- **背景**：在“回声图书馆”长大，能听见道路记忆。为了寻找失散的北斗心愿碎片踏上旅程。
- **动机**：证明自己不仅会解谜，也能把伙伴安全带回家。
- **桌面体验**：玩家获得额外信息，适合规划路线；当他公开猜测时，其他人会得到明确的讨论焦点。
- **基础数值**：活力 4，初始友情 2，手牌上限 6。
- **专属技能「星图校准」**：每轮一次，查看牌堆顶 3 张，将 1 张置顶、1 张置底、1 张放入弃牌堆；若本轮有人被帮助，友情 +1。
- **弱点 / 互动**：独自承担风险时友情 -1；布布在场时第一次“误会”不扣友情。
- **台词关键词**： “先看星星怎么说。”

### 2. 布布｜蜜糖云兔
- **种族 / 年龄感**：云兔，活泼少女感。
- **外观**：奶油白绒毛，耳朵内侧珊瑚粉，背着蜂蜜色小挎包，尾巴像一朵软云。
- **性格**：热情、善于鼓励，紧张时会连续讲冷笑话。
- **背景**：经营“临时糖果铺”，用甜味记住每个旅人的名字；她的云朵会收集大家的笑声。
- **动机**：找到让全萌境持续下雨的“无声云”，让笑声重新回到天空。
- **桌面体验**：促进交易与赠送，能把低落的队友拉回状态。
- **基础数值**：活力 5，初始友情 2，手牌上限 7。
- **专属技能「甜甜转机」**：每轮一次，指定一名玩家摸 2 张并选择 1 张赠给任意玩家；接受者友情 +1。
- **弱点 / 互动**：若连续两轮没有与人互动，活力 -1；一二在场时可把一次失败判定改为“重新尝试”。
- **台词关键词**： “先吃口甜的，办法就来了！”

### 3. 咕噜｜苔藓小熊
- **种族 / 年龄感**：苔原熊，可靠大哥哥感。
- **外观**：栗棕色短毛，肩上长一圈荧光苔藓，木桶形护腕，脚掌有叶脉纹。
- **性格**：慢热、耐心、喜欢修补旧物。
- **背景**：守护“摇摆桥”多年，记得每一块石头的脾气。
- **动机**：修好通往雾港的老桥，找到当年离开的师父。
- **基础数值**：活力 7，初始友情 1，手牌上限 5。
- **技能「稳稳接住」**：替相邻玩家承受 1 次伤害；成功后自己友情 +1，并获得“守护”标记。
- **互动钩子**：收到工具牌时额外摸 1；被拒绝帮助时不会降低友情。

### 4. 露米｜萤光水獭
- **种族 / 年龄感**：河湾水獭，机灵少女感。
- **外观**：青灰皮毛，尾巴有萤光环纹，透明护目镜挂在额头，腰间串着贝壳钥匙。
- **性格**：好奇、爱拆解机关，遇到新朋友会主动提问。
- **背景**：在“倒流河”收集会唱歌的石子，能把水流暂时倒放。
- **动机**：找回被河水带走的家族航标。
- **基础数值**：活力 5，初始友情 2，手牌上限 6。
- **技能「倒放三秒」**：回合结束后，可将刚结算的一张行动牌退回手中，并把同类型弃牌顶置；每局限 2 次。
- **互动钩子**：与同一玩家交换第二次时，双方各摸 1 张。

### 5. 叮当｜铜铃雀
- **种族 / 年龄感**：风铃雀，少年感。
- **外观**：金黄胸羽、墨蓝翼尖，脚踝系微型铜铃，飞行时留下音符光点。
- **性格**：外向、爱传话，偶尔把秘密说得太快。
- **背景**：是岛屿间的信使，翅膀下藏着一张从不迷路的地图。
- **动机**：让八岛重新恢复稳定航线。
- **基础数值**：活力 4，初始友情 2，手牌上限 6。
- **技能「铃声广播」**：公开牌堆顶 2 张，全体投票决定其中 1 张加入谁的手牌；投票平票时由叮当决定。
- **互动钩子**：每当公开信息，自己友情 +1（每轮一次）。

### 6. 栗栗｜月影刺猬
- **种族 / 年龄感**：月影刺猬，谨慎少女感。
- **外观**：紫灰软刺，刺尖像小月牙，穿带兜帽的青莓斗篷，背着缝补包。
- **性格**：害羞、观察细节、承诺过的事一定做到。
- **背景**：在“静音森林”缝补被噪声划破的梦境。
- **动机**：收集六片月影布，给森林做一张安静的夜幕。
- **基础数值**：活力 5，初始友情 1，手牌上限 6。
- **技能「月影藏针」**：将 1 张手牌盖伏；本轮首次受到负面效果时取消并翻回该牌，随后友情 +1。
- **互动钩子**：被赠送后可把赠送者的 1 点伤害转为双方各 0（每轮一次）。

### 7. 轰轰｜火花鼹鼠
- **种族 / 年龄感**：火花鼹，冒险少年感。
- **外观**：炭黑绒毛，鼻尖橙红，背着齿轮矿灯，尾巴末端冒小火星。
- **性格**：冲动、讲义气、喜欢把困难说成“热身”。
- **背景**：挖掘地下捷径时意外打通了通往梦境核心的隧道。
- **动机**：证明“最快的路”也能是安全的路。
- **基础数值**：活力 6，初始友情 1，手牌上限 5。
- **技能「轰的一下」**：弃 1 张牌，令场景威胁 -2；若威胁因此降至 0，自己受 1 伤害并摸 2 张。
- **互动钩子**：与咕噜同时在场时，守护效果可覆盖两名玩家。

### 8. 雾芽｜蘑菇狐
- **种族 / 年龄感**：雾林狐，神秘少女感。
- **外观**：奶茶色狐毛，耳尖长着一朵小蘑菇，尾巴有薄雾渐变，披风内侧是发光孢子。
- **性格**：温柔、说话有谜语，擅长安抚紧张的人。
- **背景**：能读取蘑菇圈里的旧梦，知道许多被遗忘的名字。
- **动机**：找回自己的真名，解除雾林的循环。
- **基础数值**：活力 5，初始友情 2，手牌上限 6。
- **技能「雾中改写」**：将一次判定的结果从成功改为部分成功，或从失败改为成功；使用后本局不能再次使用。
- **互动钩子**：当有人说出自己的秘密，她与该玩家各摸 1 张。

### 9. 泡泡｜潮汐海豹
- **种族 / 年龄感**：潮汐海豹，憨厚少年感。
- **外观**：浅蓝皮毛，额头有水滴形胎记，围橘色围巾，胸前挂着小浮标。
- **性格**：乐观、怕冷、记性差但记得朋友喜欢什么。
- **背景**：来自会涨潮的玻璃湖，随身携带一瓶“晴天海水”。
- **动机**：把玻璃湖的潮汐调回正常节奏。
- **基础数值**：活力 6，初始友情 2，手牌上限 6。
- **技能「泡泡护航」**：给一名玩家 2 点护盾，护盾在其下次回合开始时清除；若护盾完整保留，泡泡友情 +1。
- **互动钩子**：赠送水系牌后可立即移动到任意相邻位置。

### 10. 斑斑｜彩绘变色龙
- **种族 / 年龄感**：彩绘变色龙，机敏中性气质。
- **外观**：皮肤会随场景变色，背部有彩色笔刷纹，尾巴卷着一支短画笔。
- **性格**：善于模仿、幽默、害怕被固定标签定义。
- **背景**：为每座岛画过旗帜，却从没画过自己的颜色。
- **动机**：找到一种只属于自己的颜色。
- **基础数值**：活力 4，初始友情 2，手牌上限 7。
- **技能「借来一笔」**：复制场上任一已公开角色技能的非永久部分；复制后该技能本轮不可再被复制。
- **互动钩子**：改变站位或身份公开时，摸 1 张。

### 11. 阿团｜纸灯水母
- **种族 / 年龄感**：纸灯水母，安静成熟感。
- **外观**：半透明淡紫伞盖，触须像纸灯穗子，体内漂着一枚小月灯。
- **性格**：体贴、记得每个人的生日，面对冲突会先递出灯。
- **背景**：漂浮在梦海上，为迷路者照亮回岸的方向。
- **动机**：寻找熄灭的“第一盏灯”。
- **基础数值**：活力 5，初始友情 2，手牌上限 6。
- **技能「留一盏灯」**：标记一名玩家；其下一次濒临疲惫时改为保留 1 活力并摸 1 张。每局 2 次。
- **互动钩子**：回合结束时若无人受伤，全队友情 +1（每轮一次）。

### 12. 砾砾｜砂糖龙
- **种族 / 年龄感**：砂糖幼龙，淘气少年感。
- **外观**：薄荷绿鳞片，角像两颗方糖，翅膀是半透明糖纸，喷出的火焰是彩色糖粉。
- **性格**：嘴馋、爱收藏闪亮东西、输掉时会认真复盘。
- **背景**：守着一座会融化的糖晶山，山心藏着最后一枚心愿碎片。
- **动机**：学会在宝物和朋友之间做选择。
- **基础数值**：活力 6，初始友情 1，手牌上限 5。
- **技能「糖晶爆闪」**：弃 2 张同色牌，场景威胁 -3；若弃牌中有他人赠送的牌，再额外使一名玩家友情 +1。
- **互动钩子**：每局第一次拒绝交换时摸 2 张，但友情 -1。

## 角色平衡基准

- 低活力角色拥有信息、重试或防御技能；高活力角色承担伤害或降低威胁。
- 单局建议随机抽取 4–6 名角色，保证至少 1 名信息型、1 名守护型、1 名资源型。
- 同一角色技能描述中的“每轮一次”以该角色回合开始至下一次回合开始为周期；“每局一次”在房间内只可触发一次。
